Capturas del Monitor para TC06 (pendientes: el 2026-10-27 no habia tarjetas conectadas en PC1).

Con DOS ESP32-S3 en la misma PC (cables 17->18, 18<-17 y GND entre ellas):

  pio device list                         -> anota los dos puertos, p. ej. COM5 y COM7
  pio run -d programa-chat-uart2 -t upload --upload-port COM5
  pio run -d programa-chat-uart2 -t upload --upload-port COM7
  (terminal 1)  pio device monitor -d programa-chat-uart2 -p COM5
  (terminal 2)  pio device monitor -d programa-chat-uart2 -p COM7
